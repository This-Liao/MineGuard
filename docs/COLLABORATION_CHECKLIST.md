## 接入企业环境时才需要提供

1. 专用测试环境的 Flask/Spring Boot 地址、版本和安全接入方式。
2. 企业认证/权限接口与角色语义；不把 PDF 中未知的 permissions 数值直接映射为审批权限。
3. 可操作设备与算法白名单、明确写授权，以及 /check 对停止、不存在、失败状态的完整定义。
4. 工业接收端幂等键支持、操作回执查询及独立状态验证接口。没有这些能力不能承诺自动恢复或恰好一次执行。

生产接入先只读验收；不使用实际摄像头进行本项目的故障注入测试。不需要为本机演示购买云资源。
