## 推荐表述

1. 基于 Java / Spring Boot 实现可持久化的安全作业 Agent，支持结构化工具、RBAC、独立审批、租约恢复与可溯源中文报告。
2. 建立固定 Agent / Safety Eval；在真实 DeepSeek API 下，将固定 30 题严格成功率从 30% 提升至 96.67%，两轮复测均为 29/30，保留失败案例与 Token 回执。
   冻结后新增 24 题的一次性留出评测为 87.50%，未据此调参重测；开发者可见，不称第三方盲测。
3. 为工作流恢复、权限边界、语义向量接口和前端交互建立回归测试；接入 GitHub Actions，以 JaCoCo 指令覆盖率 ≥ 70% 作为构建门禁，2026-09-01 本地干净构建指令覆盖率为 82.84%。
