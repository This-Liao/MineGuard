## 录制方式

- 页面为本机运行的 Vue 工作台，连接本机 Spring Boot 服务；使用获得授权的演示操作员账号。
- 从登录后的页面开始采集截图，在实际点击、滚动和任务状态变化后记录关键帧，再编码为循环 GIF；不是连续等速屏幕录像。
- 保留原始 1265 × 712 画面，仅做 GIF 色板压缩和停留时间调整，没有改写页面结果或重绘界面。
- 等待时间已经压缩，阅读停留时间经过调整，不能用 GIF 时长推算模型延迟或端到端性能。
- 三张 GIF 总大小约 1.84 MiB；逐帧解码、尺寸、时长、画面变化和体积已检查。
